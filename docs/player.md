# Плеер записи

Задачи: #19, #20, #95, #110. Рабочая страница — защищённый `/player`.
Она показывает записи совещаний текущего пользователя, доступные через API.
Медиа открывается по `media_url` через same-origin cookie proxy с проверкой
владельца на каждом запросе, включая HTTP Range/206. Сырые файлы и текст не
публикуются как static и не передаются внешним API.

После выбора записи страница запрашивает последнюю завершённую версию результата
и все страницы `SegmentRead`. Частичный транскрипт не показывается. Клик по
реплике или маркеру перематывает соответствующее аудио, воспроизведение
подсвечивает текущую реплику. Ручная прокрутка панели отключает автоследование;
его можно включить снова. Отсутствие результата, пустой транскрипт, загрузка и
ошибки показаны раздельно. Спикеры и поручения не придумываются из текста.

Общий компонент `frontend/src/shared/ui/meeting-player/` поддерживает play/pause,
±10 секунд, seek, скорость 0.5–2×, громкость, буферизацию и ошибки. Время
измеряется в целых миллисекундах от начала исходного медиа. Длительность
берётся из записи; она не выводится по последней реплике. Для записей до
32 MiB браузер строит форму волны из защищённого медиа; более крупные файлы
не скачиваются целиком ради графика. Маркеры строятся из реальных таймкодов.

Приёмка на dev-ivan выполняется на двух записях из `input-audio`, загруженных
как приватные записи dev-user. Проверяются выбор обеих записей, реальные
`ResultVersion`/`SegmentRead`, seek по реплике, подсветка при воспроизведении,
HTTP Range и отсутствие ошибок в браузере. Демонстрационный синтетический
маршрут и локальный браузерный импорт удалены из продукта (#110).
