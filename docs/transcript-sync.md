контроллер и необязательная панель реплик. API и сохранение правок не затронуты.
Основа — [контракт совещаний](meeting-contract.md) и [плеер #19](player.md).

## Подключение к странице встречи

Передать сегменты текущих `recording_id` и `result_version_id`, а `source.id`
плеера установить равным `recording_id`. Компонент, владеющий хуком и панелью,
монтировать с ``key={`${recordingId}:${resultVersionId}`}``: смена результата
начинает новую сессию следования и сбрасывает запросы раскрытия.

```tsx
const player = useRef<MeetingPlayerHandle>(null);
const sync = useTranscriptSync({
  recordingId,
  resultVersionId,
  segments,
  seek: (timeMs) => player.current?.seek(timeMs),
});

<MeetingPlayer ref={player} source={source} onPositionChange={sync.onPositionChange} />
<TranscriptPanel sync={sync} />
```

Редактор Артёма может использовать `sync` без `TranscriptPanel`:

- `segments`: отфильтрованы по записи/версии и валидному интервалу, упорядочены
  по `start_ms`, затем ID. Тип — UI-проекция, не замена сгенерированного DTO.
- `activeSegmentId`: позиция из реального аудио, интервал `[start_ms, end_ms)`.
  В паузах и после последней реплики — `null`. При перекрытии побеждает самый
  поздний start, затем больший ID. Одновременно выделяется одна реплика.
- `seekSegment(id)`: возвращает `false` для отсутствующего/чужого сегмента,
  иначе вызывает seek в ms. Не вызывает play, не меняет скорость/следование.
- `reveal`: `{segmentId, sequence}` — явный переход, включая повторный клик
  на тот же источник. Редактор раскрывает реплику и фокусирует её один раз.
- `follow/setFollow`: включение возвращает текущую реплику в видимую область.
  Панель отключает следование при wheel/touchmove, клавишах прокрутки,
  начале перетаскивания полосы и прочей ручной прокрутке. Автоследование
  не переносит фокус и прокручивает только собственный viewport.
- `onPositionChange`: подключается напрямую к #19; события другой записи
  и нечисловые позиции игнорируются. Нет собственного таймера и поправок на rate.

Для каждого `source_segment_ids` поручения текущей версии найти сегмент в
`sync.segments` и вызвать `sync.seekSegment(id)`. Неизвестные ссылки показывать
недоступными; не подменять их соседней репликой. Демо содержит два источника
одного поручения и один недоступный. Переключение записи/версии и загрузку
полного набора реплик выполняет страница встречи, а не этот хук.

## Изолированная проверка

`/transcript-demo` — публичная страница с переключателем между синтетическим
примером и двумя MP3 из `input-audio/`, уже опубликованными в репозитории
по исключению в [описании кейса](case.md). Сборка помещает эти два MP3 в
`dist/client/assets`; других файлов из репозитория она не добавляет. Страница
не загружает файлы пользователя и не запрашивает API встреч. При смене
источника плеер останавливает предыдущую запись и начинает новую с паузы.

Синтетический режим создаёт 32-секундный PCM WAV в памяти браузера;
object URL освобождается при размонтировании.
Сигналы 1–8 начинаются в 0/4/8/12/16/20/24/28 s, длятся 3 s; частоты
440/550/660/770/880/990/1100/1210 Hz, между сигналами 1 s тишины.
Это временные метки для проверки, а не результат распознавания речи.
В режимах MP3 виден только плеер: для исходных записей ещё нет реплик с
таймкодами. Панель реплик и ссылки на поручения не показываются, чтобы не
создавать ложную привязку к синтетическому тексту. Интеграция с реальным
транскриптом требует результата обработки и его `result_version_id`.

В отдельной worktree без `.env` сборке нужны обязательные настройки auth даже
для синтетической страницы. Для локальной проверки использованы только
одноразовые фиктивные настройки процесса, без подключения к общей базе:

```sh
export FRONTEND_PORT=3020 HOST=127.0.0.1
export BETTER_AUTH_URL=http://127.0.0.1:3020
export BETTER_AUTH_SECRET=synthetic-demo-only-not-a-real-secret
export BETTER_AUTH_JWT_AUDIENCE=synthetic-demo
export AUTH_DATABASE_URL=postgresql://demo:demo@localhost:55420/demo
bun run --cwd frontend build
bun run --cwd frontend start
```

Это не настройки для deployment или страницы с реальными встречами.

Проверки 2026-09-23: `typecheck`, `check` (format + typed lint), `lint:fsd`,
`i18n:check` (97 сообщений в ru/kk/en), production `build` прошли.
В production-сборке через браузер проверены переходы 0/4/8/24 s, отсутствие
подсветки в тишине на 3.2 s, seek в паузе и при play, rate 2×, ручная
перемотка, отключение следования колесом и клавиатурой, повторный source jump,
недоступная ссылка и смена ru/kk/en без сброса позиции. Автоследование
прошло всю шкалу до конца: viewport сдвинулся от 0 до 314 px, следование
осталось включено, на 32 s активной реплики нет. Console warn/error: пусто.
Обе опубликованные MP3 проверены в том же браузере: длительности 274.25 и
206.03125 s, воспроизведение первой стартовало, переход ко второй остановил
первую и оставил вторую на паузе в нуле. Возврат к синтетическому режиму
восстановил панель реплик. Казахские строки в режиме MP3 проверены вручную.

Остаётся интеграция в редактор/страницу встречи и проверка на реальном
авторизованном результате #11–13. Фактическое согласование интерфейса с Артёмом
ещё не подтверждено. #20 не закрыта, push и deployment не выполнялись.
