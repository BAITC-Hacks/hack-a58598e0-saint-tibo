# Извлечение черновика из сохранённой транскрипции

Временный путь для реальных записей: `POST /api/v1/meetings/{meeting_id}/recordings/{recording_id}/results/{result_version_id}/extract`. Он читает уже сохранённые реплики и отправляет их вместе с названием и временем совещания в настроенный OpenAI-совместимый API. Аудио и STT повторно не обрабатываются. Ответ сохраняется как **непроверенный черновик** следующей ревизии review: саммари (темы, решения, открытые вопросы) и поручения. Пустой список допустим, когда оснований нет.

В текущем выпуске этот провайдер не настроен: параметры `BACKEND_EXTRACTION_API_*` остаются пустыми, операция недоступна. Основной путь #69 выполняет извлечение локальной моделью через очередь обработки. Само наличие ключа провайдера не означает, что облачная обработка включена или проверена.

Кнопка извлечения из сохранённой транскрипции скрыта по умолчанию. Она доступна только при сборке frontend с `VITE_TRANSCRIPT_EXTRACTION_ENABLED=true` и выполнении остальных условий доступности черновика. Docker build argument с этим именем по умолчанию равен `false`; любое значение, кроме строки `true`, оставляет кнопку скрытой. Включать флаг следует только одновременно с готовым и проверенным backend-провайдером. Флаг встраивается в клиентскую сборку, поэтому изменение runtime-окружения без пересборки его не переключает. Он не содержит секретов и не влияет на полную локальную обработку `target_stage=extract`.

Если настроить внешний HTTPS API, текст реальных разговоров покинет сервер; такой режим не соответствует требованию локальной обработки кейса. Для самостоятельного хостинга этого адаптера нужен внутренний совместимый `/v1/chat/completions` с поддержкой строгого `response_format=json_schema` и отдельная проверка качества. Контракт review сохраняется.

Настройка сервера: `BACKEND_EXTRACTION_API_BASE_URL` (например, HTTPS-адрес с `/v1`), `BACKEND_EXTRACTION_API_MODEL` и `BACKEND_EXTRACTION_API_KEY`. Значения хранятся только в приватном окружении. Обычный `docker compose` передаёт эти три переменные только контейнеру API. HTTP разрешён только на loopback или короткое имя внутреннего Compose-сервиса для будущего локального провайдера. Без полной конфигурации операция отвечает `503 extraction_unavailable` и не меняет review.

Операция требует право записи и владение совещанием. Запускается только для исходной ревизии `1`, чтобы не затереть ручные правки; повторный запрос возвращает `409 extraction_already_exists`. Если правка сохранена во время вызова модели, запись черновика отклоняется проверкой ревизии. Каждый пункт должен ссылаться на существующие номера реплик; сервер сопоставляет их с UUID сохранённых сегментов и отклоняет неверные ссылки. Ответ модели и текст транскрипта в логи не записываются. Вызов ограничен 90 секундами, вход — 256 KiB, ответ — 1 MiB. После ошибки review остаётся прежним.

Провайдер извлекает смысл, но автоматическая проверка схемы и ссылок не доказывает правильность поручений, сроков и решений. Пользователь должен открыть черновик, исправить его и подтвердить review перед экспортом.
