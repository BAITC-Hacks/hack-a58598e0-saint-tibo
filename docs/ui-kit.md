# Общий UI (#46)

Единственный базовый набор — `frontend/src/shared/ui/shadcn` (Base UI). Перед новым контролом ищите существующий компонент там. Токены цветов и шрифта — в `frontend/src/app/styles/globals.css`, значения и правила — в корневом `DESIGN.md`. Менять API общего компонента следует в его файле и во всех вызовах одним изменением; новая история Storybook фиксирует новое состояние. Владелец общих контрактов — UI-ветка #46; предметные композиции принадлежат экранам по `docs/ui-architecture.md`.

| Элемент | API и применение | Состояния |
| --- | --- | --- |
| `Button` | `variant=default / outline / secondary / ghost / destructive / link`; `size=xs / sm / default / lg / icon*`. Иконка из lucide рядом с текстом, у одной иконки обязательно `aria-label`. Для ссылки — `nativeButton={false}` и `render={<Link ... />}`. | `disabled` для ожидания и невозможного действия; loading имеет видимый текст. Hover, active и `focus-visible` заданы в одном компоненте. |
| `Input`, `Textarea` | Метка через `label htmlFor` или `FieldLabel`; размер по умолчанию 36 px. | `required`, `disabled`, `aria-invalid`, `FieldError`; ошибка с текстом, не только с красной рамкой. |
| `Select` | Base UI Select с `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`; отдельная видимая метка. | Клавиатура, `disabled`, `aria-invalid`; длинные RU/KK/EN значения не обрезать без доступного полного имени. |
| `Dialog`, `AlertDialog` | `DialogTrigger`, `DialogContent`, `DialogTitle`; опасное подтверждение через `AlertDialog`. | Возврат фокуса и Escape обеспечивает Base UI; действие блокируется на время запроса. |
| `Toast` | Существующий `Toast`/глобальный обработчик ошибок мутаций. | Сообщения из словарей RU/KK/EN; без параллельного локального toast-сервиса. |
| `Card`, `Badge` | Поверхность и семантический статус; подпись статуса обязательна. | Цвет из темы и статусных токенов, не локальный HEX. |
| `RoutePending`, `RouteError`, `RouteNotFound` | Общие состояния маршрута. | Доступные текст, `role=alert`, повтор или ссылка. |

Точки размеров: контроль 36 px, малый 32 px, крупный 40 px, иконка не меньше 44 × 44 px на сенсорном экране. У всех действий видимый клавиатурный фокус 2 px, нативный disabled, контрастный текст и корректное имя для screen reader. Тема и настройки доступности наследуются от приложения; не ставьте локальный фон в обход токенов. Кнопка, поле и диалог уже существуют; отдельная библиотека для них не нужна.

Исключение: `Card` в вендорной обёртке получил проектные границу и радиус 2 px вместо исходных округления/тени, чтобы существующие экраны и будущие общие карточки использовали один контракт. Остальные обёртки сохранены без форка. Медиаплеер и захват остаются в `shared/ui` по существующему контракту, но не служат образцом для произвольного общего компонента.
