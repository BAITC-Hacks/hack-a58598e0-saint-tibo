# Ручная проверка на dev-сервере

CI/CD и автоматического развёртывания нет. Каждый участник запускает свою
версию на своём сервере и проверяет реальный пользовательский сценарий.

| Участник | SSH alias |
| --- | --- |
| Данил | `saint-dev-danil` |
| Иван | `saint-dev-ivan` |
| Артём | `saint-dev-artem` |

SSH-доступ настраивается отдельно. Серверу нужны Docker Engine,
Docker Compose, Python 3 и curl, а SSH-пользователю — доступ к Docker
и `/opt/saint-tibo`. GitHub-токен на сервере не требуется.

## Запуск выбранного коммита

Из чистой рабочей копии с закоммиченными изменениями:

```sh
sh scripts/dev-deploy.sh saint-dev-danil
```

Заменить alias на свой. Команда отправляет только tracked-файлы текущего
коммита, собирает образы, выполняет миграции и ждёт health checks.
Секреты генерируются на сервере при первом запуске и остаются
в `/opt/saint-tibo/.env` с правами `600`. Повторный запуск сохраняет
окружение и данные. Версии лежат в `releases/<sha>`, `current` указывает
на последний успешно проверенный запуск. Команда запускается только вручную.

Порты доступны на loopback сервера. Для браузера открыть SSH-туннель:

```sh
ssh -N -L 3000:127.0.0.1:3000 -L 8000:127.0.0.1:8000 saint-dev-danil
```

Затем открыть `http://localhost:3000` и `http://localhost:8000/docs`.
Локальные порты 3000/8000 должны быть свободны. При их изменении также
согласовать `BETTER_AUTH_URL`, `BACKEND_AUTH_ISSUER`, `BACKEND_CORS_ORIGINS`
и `VITE_API_URL` в серверном `.env`, затем заново собрать frontend.
Публичный домен и HTTPS настраиваются отдельно.

## Что проверять

- Вход, регистрация, выход; чужой аккаунт не получает права администратора.
- Изменённый сценарий целиком в RU/KK/EN, включая ошибку и пустой результат.
- `GET /health/ready`, консоль браузера и серверные логи:

```sh
ssh saint-dev-danil 'cd /opt/saint-tibo/current && docker compose logs --tail=60 backend frontend'
```

Указать в issue проверенный SHA и результат. После слияния в `dev`
обновить свою рабочую копию и вручную повторить запуск на своём сервере.
Соседние dev-серверы и production эта команда не изменяет.
