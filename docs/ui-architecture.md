# Размещение UI: FSD и Atomic Design (#47)

FSD задаёт зависимости и пути. Atomic Design здесь только описывает размер композиции; папок `atoms`, `molecules` и `organisms` нет.

| Масштаб | Где живёт | Пример |
| --- | --- | --- |
| Базовый контрол (атом) | `frontend/src/shared/ui/shadcn` | `Button`, `Input`, `Select`, `Dialog` |
| Общая малая композиция (молекула) | `frontend/src/shared/ui` после реального повторного использования | `RouteError`, переключатель локали |
| Предметный блок (организм) | сначала `pages/<screen>/ui`; при повторном использовании — `entities/<domain>` или `features/<action>` | строка встречи в списке; действие публикации протокола |
| Каркас и страница | `app/layouts` и `pages/<screen>` | `AppShell`, экран совещаний |

Новый компонент сначала помещается рядом с экраном. В `shared/ui` он переходит, когда одинаковые контракт и поведение нужны нескольким экранам; предметную логику в `shared` не переносить. `features` содержит повторяемое действие пользователя, `entities` — повторяемое представление предметных данных. `widgets` пока не нужен. Один контрол одного назначения: искать в `shared/ui` до добавления локального аналога.

Маршрут в `app/routes` содержит `createFileRoute`, проверку доступа, `loader` и импорт публичного `pages/<screen>/index.ts`. Запросы идут через существующий генерируемый API-клиент и TanStack Query. Внутренности другого слайса не импортировать; зависимости направлены `app → pages → features → entities → shared`, слайсы одного слоя друг друга не импортируют. `bun run --cwd frontend lint:fsd` проверяет границы. Для экранов списка совещаний и протокола #83: их частные строки, панели и формы остаются внутри соответствующей `pages` до подтверждённого повторения.

Исключения текущего кода: медиаплеер и захват лежат в `shared/ui`, потому что ими пользуются отдельные существующие маршруты и их контракт передаётся другим экранам; их медиалогику не копировать. `src/shared/ui/shadcn/**` — вендорная Base UI обёртка: варианты меняются централизованно, без локального второго набора CSS-кнопок. `src/shared/api/generated/**` и `app/routeTree.gen.ts` не редактировать вручную.
