и работы агентов. Аккаунты обычные (`user`), принадлежат только демо и имеют

этих общих демо-аккаунтов доступно каждому, кто читает этот файл.

Проверены переход к реплике 00:44 и воспроизведение, снятие подтверждения при
редактировании, а также сохранность локальных полей при конфликте двух вкладок.

Готовая встреча в этом демо-аккаунте:
[Демо: совещание №2 — проход 23 сентября](https://dev-danil.saint-tibo.win/meetings/08e8afdd-1100-42c8-94dd-09db9a684dd4).
Её дата — дата демонстрации; исходная дата записи и календарные сроки
не выдумывались. Саммари и поручение внесены вручную и явно так обозначены.
Этот результат не доказывает готовность автоматического извлечения.
Production обновлён до `7d5b481` через PR #114. Обычный демо-вход и основной
интерфейс подтверждены в браузере; отдельный фактический API-проход
загрузка → локальный STT → ручная редакция → PDF/DOCX также завершён.
[Запись проверки production](https://github.com/BAITC-Hacks/hack-a58598e0-saint-tibo/issues/94#issuecomment-5794357831).
Свежие версии после этого снимка проверять по #94; пользовательские встречи
в постоянном демо-аккаунте не относятся к одноразовым данным для очистки.

1. Создать совещание с названием, действительной датой, часовым поясом и участниками.
2. Загрузить разрешённую аудиозапись. Образцы организаторов находятся в
   [input-audio](input-audio/); это отдельное разрешённое владельцем исключение.
3. Запустить локальную обработку и дождаться сохранённого транскрипта.
4. Воспроизвести запись и перейти к исходной реплике по таймкоду.
5. Проверить и сохранить поручения и саммари. Неизвестные исполнитель и срок
   остаются неизвестными; модельный черновик требует человеческой проверки.
6. Явно подтвердить выбранную редакцию, скачать PDF и DOCX этой редакции.

Транскрипт не равен готовому протоколу. До отдельной приёмки #69/#13
автоматическое извлечение не считается законченным; #12 отвечает за спикеров.
Качество казахской и смешанной речи пока имеет известные ограничения (#11/#70).
Для демонстрации транскрипта и плеера используйте сохранённую встречу выше.
Ускорение распознавания на NVIDIA GPU готовится отдельно; успешная CPU-обработка
не является подтверждением запуска GPU.

## Для агентов и координатора

- Репозиторий: https://github.com/BAITC-Hacks/hack-a58598e0-saint-tibo
- Перед работой: `git fetch origin`, прочитать свежие #94/#107 и claims своей задачи.
- Состояние: [docs/current-state.md](docs/current-state.md),
  [docs/integration-plan.md](docs/integration-plan.md),
  [.serena/plans/NEXT-SESSION.md](.serena/plans/NEXT-SESSION.md).
- Настроенные SSH-алиасы: `saint-dev-danil` и `saint-prod`.
  Проверка фактической версии: `ssh saint-dev-danil 'readlink /opt/saint-tibo/current'`.
  Для production заменить alias на `saint-prod`.
- Git push сам по себе не выполняет деплой. Единственный координатор выпуска
  сериализует merge и deploy по [docs/dev-server.md](docs/dev-server.md).
- Серверные SSH-ключи, `.env` и настоящие ключи провайдеров принадлежат защищённой
  конфигурации окружения. Этот файл содержит только намеренно публичный демо-вход.
- При недоступности демо-входа проверить health и версию; не включать dev-login
  на production и не менять чужие аккаунты.
- Тестовые наборы и линтеры по текущему решению владельца не запускаются:
  поставка подтверждается сборкой и фактическим сценарием на назначенном сервере.
